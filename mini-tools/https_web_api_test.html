HTTPS Web API テンプレート

① カメラ起動（OS標準カメラ連動）

既存のカメラアプリを起動し、撮影後にブラウザへ戻します。

② カメラストリーム（生映像・マイク）

ブラウザ内にリアルタイム映像を描画します（ARやQR読取の基盤）。

ここに状態が表示されます

③ 高精度GPS（位置情報取得）

端末のGPSから正確な緯度・経度、移動速度を取得します。

ここに位置情報が表示されます

④ 物理センサー（ジャイロ・加速度）

スマホの傾きや、振った衝撃を検知します（iOSはユーザー許可必須）。

ここに傾きが表示されます

⑤ バイブレーション（※Androidのみ）

指定したパターン（例: 200ms振動→100ms停止→200ms振動）で震わせます。

⑥ 音声合成（文字読み上げ）

端末に内蔵されている音声エンジンを使って、テキストを流暢に喋らせます。

⑦ バッテリー状態（※Chrome系のみ）

現在の残量や、充電中かどうかをリアルタイムに監視します。

ここに残量が表示されます

⑧ OS標準シェア機能の呼び出し

ブラウザから、スマホ標準の共有メニュー（LINEやAirDropなど）を開きます。
